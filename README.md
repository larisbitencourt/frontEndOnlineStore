🛒 Frontend Online Store

Neste projeto criei uma versão simplificada de um e-commerce consumindo a API do Mercado Livre. A aplicação permite que usuários busquem produtos por termos, filtrem por categorias e gerenciem um carrinho de compras completo, tudo com dados em tempo real.

➤ Tecnologias Utilizadas

React: Biblioteca principal para construção da interface e gerenciamento de estados dinâmicos.

React Router v5: Navegação entre as páginas de listagem, detalhes do produto e carrinho de compras.

Mercado Livre API: Integração para busca de produtos, categorias e detalhes técnicos.

JavaScript (ES6+): Uso extensivo de Promises e Fetch API para operações assíncronas.

➤ Principais Funcionalidades

Busca e Filtro: Pesquisa por texto ou navegação através de categorias dinâmicas vindas da API.

Carrinho de Compras: Adição de itens, controle de quantidade (limitado pelo estoque) e remoção de produtos.

Avaliações: Sistema de comentários e notas para os produtos, persistidos no LocalStorage.

Checkout Simulado: Validação de formulário de compra com resumo total dos itens.

➤ Habilidades Desenvolvidas

Organização de fluxo de trabalho através de metodologias ágeis (Kanban).

Manipulação de rotas dinâmicas e parâmetros de URL.
